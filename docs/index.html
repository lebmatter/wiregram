A multi-backend chat client for the terminal. Manage chats and AI chat agents easily, written in Go.

Download GitHub

What it does

Multi-backend

Telegram, WhatsApp, Matrix and Mattermost accounts side by side. Alt+1..9 jumps between them.

Terminal powered

Keyboard only. Replies, threads, reactions, search and uploads, with media in mpv or inline in Kitty.

AI Chat Agents

Optional bots that answer your DMs through any OpenAI-compatible provider, or draft replies for you to approve.

One static binary

Pure Go, no cgo. Credentials live in the OS keyring; sessions stay in ~/.config/wiregram.

Two modes

Chat Agents work with any OpenAI-compatible provider. They are set up through a guided wizard, can suggest replies for you to approve or answer on their own, and never start a conversation.

Download

One file, no installer and no runtime. Pick your platform from the latest release.

Linux x86_64 Linux ARM64 macOS Apple Silicon macOS Intel

Or from the terminal:

# Linux x86_64; swap the suffix for your platform
$ curl -fLo wiregram https://github.com/lebmatter/wiregram/releases/latest/download/wiregram-linux-amd64
$ chmod +x wiregram
$ ./wiregram

Build from source

Requires Go 1.26 or newer and an interactive terminal.

$ git clone https://github.com/lebmatter/wiregram
$ cd wiregram
$ make
$ ./wiregram

Press ? inside the app for shortcuts, or run wiregram -h. Install mpv to open attachments, and use Kitty to see images inline.
