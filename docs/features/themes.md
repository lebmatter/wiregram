# Themes

Wiregram has two themes. Pick one in **Settings → Themes…**: each shows as a sample card,
the arrows move between them, and <kbd>Enter</kbd> applies it to every screen. The choice
is saved as the `theme` setting.

| Theme | Accent | Look |
|-------|--------|------|
| **Zest** (default) | Lime `#E8FE96` | Lime on purples, from the website |
| **Copper** | Orange (256-colour 214) | Copper on greys |

A theme sets the accent, subtle, dim, selection, mention and badge colours. The rest are
the same in every theme:

- status glyphs
- chat kinds: DM green, group blue, channel yellow
- links (underlined)
- nick colours, one per sender

Violet is kept for [AI powered chat bots](/features/chat-bots): the ✦ icon, the suggestion card
and messages a bot sent.
